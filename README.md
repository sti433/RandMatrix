# 🎲 RandMatrix

A simple and clean C# console program that generates an array filled with random numbers and displays them neatly in the console.  
Perfect for beginners learning about **arrays**, **loops**, and **random number generation** in C#. ✨

---

## 🌟 Overview
This project demonstrates:
- How to create and initialize arrays
- How to use the `Random` class
- How to fill an array with random numbers
- How to display all elements in a readable format  

---

## 🧠 How It Works
1. The user enters the **number of elements** (`n`)
2. The program creates an integer array of size `n`
3. Each element is filled with a random number between **1 and 100**
4. Finally, all numbers are printed in one line, separated by spaces 💫
